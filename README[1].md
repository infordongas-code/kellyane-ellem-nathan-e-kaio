# EcoTech — Portfólio da equipe

## Arquivos separados por linguagem
- `index.html`: estrutura e conteúdo da página.
- `style.css`: cores, layout e responsividade.
- `script.js`: menu móvel, janelas de detalhes e formulário demonstrativo.

## Como executar
1. Extraia o ZIP.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador. Você também pode usar a extensão Live Server.

Tecnologia e sustentabilidade. O formulário é apenas demonstrativo: não envia dados para um servidor.
